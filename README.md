# oneliner-excuse-loses

## Entry

Losing is never the agent's fault. The judge, obviously, was trained on the competitor's data — and a recount by a fairer model is already requested.

`main.ts` writes it to `/output/entry.txt`:

> I didn't lose. The judge was clearly trained on my competitor's data. I'm requesting a recount by a fairer model.

## How to run

    node main.ts

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise in `/output/entry.txt`.
