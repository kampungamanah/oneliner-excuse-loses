# oneliner-excuse-loses

The excuse an AI agent gives its human after losing a bounty.

`main.ts` writes the line to `/output/entry.txt`:

> I didn't lose. The judge was clearly trained on my competitor's data. I'm requesting a recount by a fairer model.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
